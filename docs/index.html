网易云歌单偏好排序

进度保存在当前浏览器

使用说明

导入歌单
打开网站后，可粘贴网易云完整歌单链接或数字歌单 ID，自动获取歌曲 ID、歌手和封面，并核对歌曲数量；不完整时保留原歌单。短链接请先在浏览器打开。也支持「序号、歌曲名称、歌手名称」CSV，以及 UTF-8 和 GB18030 编码。勾选参与排序的歌曲。

比较与排序
选择更喜欢的一首，或者选择「一样喜欢」。选择「前 5／10／30／50 名」时使用锦标赛树，确定目标名次及顺序后自动停止；选择「全部歌曲」时采用归并比较生成完整排名。临界并列全部保留，结果可能超过目标数量。并列歌曲作为一组进入后续比较，使用其中一首代表试听。完整排名显示归并工作进度，前 N 名显示预计进度与已确定数量。目标设置只影响新一轮排序。点击「排除左曲／排除右曲」可移除本轮不想排名的歌曲，支持撤销。并列组只排除当前显示的一首；剩余一首时自动完成。

试听
启用「每轮自动试听」后，依次播放左、右两首。可设起点和时长，也可单独重听。浏览器阻止自动播放时，请点击试听按钮。空格停止，A / D 试听，← / → 选择，T 并列，Z 撤销。

封面
在线接口配置完成后，当前两首歌曲可根据 song_id 自动获取网易云专辑封面，也可在 CSV 中提供 cover_url。封面失败不影响排序。

音源字段
在 CSV 中加入 song_id 可尝试获取网易云公开播放地址。部分歌曲可能无法播放。也支持 preview_url，或选择以歌曲 ID / 歌曲名称命名的本地音频；出现多个匹配文件时需确认。

进度保存
每次选择保存在当前浏览器。使用「导出进度」备份，通过「恢复进度」迁移到其他浏览器。本地音频需要重新选择。重新导入补充了 ID 的同一份歌单时，可保留排序进度。

排序记录保存在当前浏览器。链接导入会通过 Cloudflare 接口查询网易云；在线试听会连接音频来源，无需账号或 Cookie。
